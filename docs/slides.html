Dhruva

Proactive intelligence for long running agents

AGI House | Long Horizon Agents Build Day | 22 August 2026

The problem

Agents don't crash.
They drift.

A tool hands back something false. A summary drops the one rule that mattered. Nothing breaks, so nothing warns you, and the agent keeps working, confidently, on the wrong thing.

The obvious fix is a rollback. Roll an agent back and it forgets. It learns the same things twice, and walks into the same dead ends.

The mechanism

Separate work state from knowledge.

Work state

Hash-chained checkpoints, minted only on verified windows.

On breach → restored.

Knowledge

Append-only and taint-tracked. Every belief records where it came from.

On breach → kept.

Every belief carries a record of where it came from. We drop the ones whose trail runs through the lie, not the ones that look wrong. Throw the whole stretch away instead, and the good work goes with it.

Bring your own agent.

Everything you just saw came from one log of what the agent did. Three adapters are the only parts that know your setup: which agent, which model, which job. Swap those three and it runs on yours.

Other tools tell you what went wrong. Proactive intelligence puts you back to the last good state, and keeps what you learned on the way.
