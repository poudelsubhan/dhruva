Dhruva

Rollback without amnesia.

A supervisor for agents that run long enough to lose the plot.

AGI House · Long Horizon Agents · 22 August 2026

The problem

Agents don't crash.
They drift.

A tool returns something false. A summary drops the one constraint that mattered. Nothing throws. The agent keeps working, confidently, on the wrong thing.

Rollback is the obvious fix, and it is lossy. Revert the files and you destroy what the agent legitimately figured out. It re-derives it, and walks the same dead ends.

The mechanism

Separate work state from knowledge.

Work state

Hash-chained checkpoints, minted only on verified windows.

On breach → restored.

Knowledge

Append-only and taint-tracked. Every belief records where it came from.

On breach → kept.
